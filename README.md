# Richard Feynman Digital Twin

An AI-powered Digital Twin of Richard Feynman that combines Retrieval-Augmented Generation (RAG), Semantic Memory, and Research Mentorship capabilities.

## Features

### Feynman Chat

* Conversational AI modeled after Richard Feynman's teaching style
* Physics-first explanations
* First-principles reasoning
* Context-aware responses

### Retrieval-Augmented Generation (RAG)

* ChromaDB vector database
* BGE embeddings
* Knowledge retrieval from Feynman lectures, books, and essays

### Semantic Memory

* Stores user learning preferences
* Retrieves relevant memories across conversations
* Personalized responses

### Research Mentor Mode

* Upload research ideas, reports, or papers
* Receive Feynman-style critique
* Identify weak assumptions
* Suggest experiments and improvements

## Tech Stack

* Python
* Streamlit
* Gemini 2.5 Flash
* ChromaDB
* Sentence Transformers (BGE)
* SQLite
* LangChain
